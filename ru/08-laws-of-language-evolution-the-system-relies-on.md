# Законы языковой эволюции, на которые опирается система

«Общие лингвистические законы» конкретизируются как пять видов знаний, каждый из которых хранится как данные, а не как вручную написанный код:

| Принцип | Как закодирован | Где используется |
|----|----|----|
| Регулярность звуковых изменений: изменение затрагивает все слова с тем же звуком в том же окружении | Таблицы соответствий, выученные EM; принимаются только регулярно повторяющиеся соответствия | Шаги 1–3 |
| Направленные тенденции звуковых изменений (лениция, палатализация перед передними гласными, оглушение на конце слова, редукция гласных, ассимиляция) | Априорные вероятности типов изменений по базам засвидетельствованных звуковых изменений | Инициализация и регуляризация таблицы соответствий |
| Генеалогическое наследование: родственные языки сохраняют морфологию общего предка; устойчивые признаки меняются медленно | Дерево Glottolog; восполнение признаков с весами по расстоянию в дереве | Ранжирование доноров, типологические априорные данные |
| Типологические универсалии: импликативные тенденции (например, языки с глаголом в конце обычно имеют послелоги; предпочтение суффиксации) | Ограничения и априорные распределения над признаками Grambank/WALS | Шаг 5 |
| Пути грамматикализации: грамматические показатели развиваются из лексических слов по повторяющимся путям (например, «идти» → будущее время) | Отображения «источник → результат» для интерпретации аффиксов с неясным значением | Приписывание грамматических признаков индуцированным аффиксам |

> Нейросетевые модели реконструкции (предсказание рефлексов когнатов, реконструкция праформ) могут заменить EM-обучение соответствий, когда для семьи накопится достаточно наборов когнатов: именно они стали сильнейшими системами на соревновании SIGTYP 2022. EM-обучение остаётся запасным вариантом для семей с малым объёмом данных.
