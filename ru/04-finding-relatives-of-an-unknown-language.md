# Поиск родственников неизвестного языка

Для неизвестного языка системе нужен небольшой набор языков-*доноров*, чьи грамматики можно перенести, и оценка места языка в генеалогическом дереве Glottolog. Ни один сигнал не надёжен сам по себе: общая лексика может быть заимствованной, похожее написание может отражать лишь общую орфографическую традицию. Поэтому ранжировщик объединяет четыре независимых сигнала, следуя подходу LangRank — обучению тому, какие признаки предсказывают успешный перенос.

| Сигнал | Как вычисляется | Что отражает |
|----|----|----|
| Распределение LID | Отвергнутое распределение из этапа распознавания, агрегированное по всем фрагментам | Внешнее сходство; дёшево и доступно сразу |
| Профиль символьных n-грамм | Ранговое расстояние Кавнара–Тренкла («out-of-place») и косинусное расстояние профилей 1–5-грамм до эталонных корпусов языков-кандидатов | Фонотактику и орфографию |
| Лексическое родство (когнаты) | Самые частотные словоформы целевого текста выравниваются со словарями кандидатов (выравнивание SCA); оценка в духе LexStat вознаграждает *регулярно повторяющиеся* звуковые соответствия, а не случайное сходство; доля вероятных когнатов в базовой лексике | Генеалогическое родство; самый сильный сигнал при достаточном объёме текста |
| Типологический отпечаток | Признаки, оценённые по сырому тексту (среднее число морфов на слово по сегментации без учителя, доля префиксов и суффиксов, частота редупликации, признаки порядка слов по частотным служебным словам), сравниваются с векторами Grambank/URIEL+ | Структурное сходство; полезно, когда родственники далёкие или неизвестны |

Ранжировщик на градиентном бустинге (как в LangRank) объединяет сигналы с априорными данными (письменность, география языков-кандидатов, объём грамматики каждого кандидата) и возвращает ранжированный список доноров. Место в дереве оценивается как ближайший общий предок лучших доноров в Glottolog, взвешенный по их оценкам. Если ни один донор не проходит порог по когнатам, язык рассматривается как возможный изолят: тогда уровень C опирается только на индукцию без учителя и типологические априорные данные.

    # ранжирование языков-доноров для неизвестного языка U
    def find_relatives(U_text, posterior, candidates):
        freq_types = most_frequent_types(U_text, n=2000)
        for L in candidates:                                  # предварительно отобраны по письменности, географии, LID
            f_post  = posterior.get(L, 0)
            f_ngram = out_of_place(ngram_profile(U_text), profile[L])
            f_cog   = lexstat_cognate_share(freq_types, lexicon[L])   # только регулярные соответствия
            f_typo  = cosine(estimate_typology(U_text), grambank_vec[L])
            score[L] = ranker.predict([f_post, f_ngram, f_cog, f_typo, prior(L)])
        donors = top_k(score, k=5)
        position = weighted_lca(glottolog, donors, score)
        return donors, position, is_isolate(f_cog_max < TAU_COG)
