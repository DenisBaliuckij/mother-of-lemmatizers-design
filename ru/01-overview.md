# Обзор

На входе — произвольный текст на любом языке и в любой письменности. На выходе — тот же текст, где для каждого слова указана лемма, а также определённый язык, грамматика, по которой получена лемма, и уверенность. Все тексты проходят общий этап распознавания языка, после чего направляются в один из трёх уровней в зависимости от того, что системе известно о языке:

## Уровень A · правила есть

*Язык распознан, есть проверенная грамматика*

Анализатор на правилах предлагает все возможные леммы, контекстная нейросетевая модель выбирает из них. Максимальная точность, каждое решение объяснимо.

## Уровень B · язык известен, правил нет

*Язык распознан, машиночитаемой грамматики нет*

Правила извлекаются из грамматик в каталоге документов и индуцируются из текстов, затем компилируются в тот же формат правил.

## Уровень C · неизвестный язык

*Распознаватель отвергает все известные метки*

Ближайшие родственники находятся по генеалогическому дереву; их грамматики переносятся через выученные звуковые соответствия, подгоняются к тексту и проверяются типологическими универсалиями.

Грамматики уровней B и C — предварительные. Они хранятся вместе с происхождением и оценкой уверенности, используются сразу, а на уровень A переводятся только после проверки: сначала автоматической, затем лингвистом. Каждый обработанный так язык улучшает работу системы для его соседей по дереву.
