# Соответствие нашей инфраструктуре

Большая часть нужных знаний уже собирается на corpus-host:

| Элемент проекта | Имеющийся ресурс | Состояние (27.09.2026) |
|----|----|----|
| Перечень языков и генеалогическое дерево | Список языков Glottolog на сервере | 8 624 языка |
| Грамматики для уровня B | Каталог документов, поле «описываемый язык» | 1 718 языков с подтверждённой грамматикой |
| Формат хранилища грамматик | lingua-rules (шаблоны правил ASP, генераторы, эталонные тесты) | Проверенные правила для английского, немецкого, русского, финского |
| Извлечение правил и модель ранжирования родственников | Локальная LLM на RTX 5090 (qwen3.8, контекст 128k) | Работает; уже классифицирует документы каталога |
| Поиск грамматик | REST API каталога корпуса (`/corpus/api/documents?described=…`) | Работает, HTTPS |
| Тексты для индукции и n-граммных профилей | Языковой корпус и коллекции грамматик | ≈ 290 000 зарегистрированных документов |

Недостающие части: модели GlotLID/OpenLID, данные UD и UniMorph, векторы Grambank/URIEL+ и реализация модуля обучения соответствий (LingPy предоставляет выравнивание SCA и LexStat).
