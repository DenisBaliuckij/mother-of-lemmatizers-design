# Схема архитектуры

```mermaid
flowchart TD
  IN[/"Входной текст"/] --> NORM["Нормализация<br/>Unicode NFC · определение письменности · транслитерация в латиницу для оценок"]
  NORM --> SEG["Сегментация<br/>предложения · токены · разбиение на слова с учётом письменности"]
  SEG --> LID{"Распознавание языка<br/>ансамбль GlotLID + OpenLID<br/>MaskLID для смешанных текстов<br/>отказ для неизвестных"}
  LID -->|"известен + правила"| A["Уровень A<br/>анализатор на правилах → варианты лемм<br/>→ контекстный выбор"]
  LID -->|"известен, правил нет"| B["Уровень B<br/>извлечение правил из грамматик<br/>+ морфология без учителя"]
  LID -->|"неизвестен"| REL["Поиск родственников<br/>n-граммное · лексическое · типологическое сходство<br/>ранжированные доноры + место в дереве"]
  REL --> C["Уровень C<br/>порождение грамматики<br/>звуковые соответствия · перенос аффиксов<br/>индукция · универсалии"]
  B --> STORE[("Хранилище грамматик<br/>шаблоны ASP lingua-rules<br/>статус: предварительная")]
  C --> STORE
  STORE --> ENGINE["Движок лемматизации<br/>общий для всех уровней"]
  A --> ENGINE
  ENGINE --> OUT[/"Леммы + язык + уверенность + происхождение"/]
  STORE -. "проверка" .-> REVIEW["Валидация<br/>покрытие · устойчивость · экспертиза"]
  REVIEW -. "перевод в проверенные" .-> CURATED[("Проверенные грамматики<br/>уровень A")]
  CURATED --> A
  KB[("Базы знаний<br/>дерево Glottolog · Grambank/WALS/URIEL+<br/>UniMorph · трибанки UD · словари")] --- REL
  KB --- C
  DOCS[("Каталог документов<br/>грамматики по описываемому языку")] --- B
  DOCS --- C
  classDef known fill:#e4e8f4,stroke:#2e3f7a,stroke-width:2px,color:#1f2421
  classDef inferred fill:#f5ebd8,stroke:#a9741c,stroke-width:2px,stroke-dasharray:5 3,color:#1f2421
  class A,CURATED known
  class B,C,REL,STORE inferred
```

*Рис. 1. Компоненты и потоки данных. Сплошной синий — проверенные знания; пунктирный охристый — выведенные знания с оценкой уверенности, ожидающие проверки.*

## Компоненты

| Компонент | Задача | Метод |
|----|----|----|
| Нормализация | Сделать тексты из разных источников сопоставимыми | Unicode NFC, удаление символов нулевой ширины, определение письменности по свойству Unicode Script (ISO 15924), романизация (в духе uroman) только для оценки сходства, никогда для вывода |
| Сегментация | Предложения и словоформы | Правила для письменностей с пробелами; словарная/статистическая сегментация для письменностей без пробелов (тайская, китайская, японская) |
| Распознавание языка | Метка языка для каждого фрагмента или «неизвестен» | Ансамбль классификаторов fastText, обнаружение переключения кодов, откалиброванный отказ (раздел «Распознавание языка») |
| Поиск родственников | Для неизвестного языка: доноры и место в дереве | n-граммное, лексическое (когнаты) и типологическое сходство, объединённые обученным ранжировщиком |
| Хранилище грамматик | Единый формат всех грамматик | Шаблоны парадигм и правил в формате ASP lingua-rules; у каждого правила — уверенность, происхождение и статус |
| Движок лемматизации | Словоформа → лемма в контексте | Анализатор на правилах порождает варианты; нейросетевая модель скриптов редактирования оценивает их в контексте; угадыватель обрабатывает незнакомые слова |
| Валидация | Решить, когда выведенным правилам можно доверять | Покрытие корпуса, устойчивость на бутстрэп-выборках, обратная генерация, отложенные проверки, очередь на экспертизу |
